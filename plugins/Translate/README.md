# Translate Messages (Vendetta)

Plugin translate tin nhắn gửi đi và dịch tin nhắn incoming từ menu nhấn giữ.

- Provider mặc định: Google Translate.
- Có thể đổi sang Gemini bằng cách nhập API key trong settings.
- Mặc định incoming: `auto` → `vi`; outgoing: `auto` → `en`.
- Dùng `/translate` để bật/tắt auto translate.
